# ReelTerminal v1.2.0

这次更新让 Agent 与人的协作剪辑更完整：更方便地管理工程版本，更好地分析和处理音频，也修复了实际创作中遇到的一批编辑、保存和导出问题。

## 主要更新

- 存档树：保存工程节点、预览历史版本，在不同创作阶段之间切换。
- 多项目协作：改进 CLI 对多项目、多工作区和多个 Agent 的支持，编辑结果同步到 GUI。
- 音频分析与处理：增强 Agent 获取音频分析结果的能力，支持音量归一化，便于后续剪辑和配音调整。
- 界面与编辑体验：优化部分面板和弹窗，改进时间线、字幕导入及编辑操作。
- 稳定性改进：修复保存、撤销、异常恢复及导出相关问题，减少重复导出的资源开销。

## 下载

- Windows x64：下载安装程序，或选择 ZIP 解压版。
- macOS：1.2.0 安装包正在准备，完成验证后补充。

## 使用提醒

- Windows 安装包尚未代码签名，系统可能显示未知发布者提示。
- 建议升级前备份重要工程。长时间、高负载编辑仍可能出现较高内存占用；个别环境的启动、拖动或剪贴板操作存在待排查问题。
- 遇到问题欢迎提交 Issue，并附上系统版本、操作步骤及必要的脱敏信息。

宣传片展示了主要工作流，部分界面与功能以当前版本为准。
