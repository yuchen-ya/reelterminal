# 存档点与当前编辑

状态：已实施，2026-10-09；开发者回归不代替独立用户验收。界面依据用户批准的 [检查器方案](INSPECTOR-VERSIONS-BOARD-UX.md)。本文件替代旧常驻横向轨迹和看板模态页的说明；[原独立验收](NODE-UX-ACCEPTANCE-2026-10-09.md) 保留原结论，修复证据另见修复报告。

## 界面

状态行只有低强调的“● 存档”和“看板”入口，不增加存档行或按节点数量预留高度。右侧默认显示原属性检查器；底部入口按需打开存档或看板面板，关闭面板返回属性，没有常驻导航行。

- 当前入口只打开存档记录并定位实际编辑基准，不创建存档、不采用内容、不跳播放头；没有存档时显示诚实空状态。
- 存档记录纵向排列，较新在上，真实父子连线连接到共同祖先。小点的颜色由不可变身份稳定分配，未选中变暗；当前用细环和文字，预览用虚线环和文字。已留存试剪用小菱形；未留存方案留在项目菜单。
- 记录使用约30像素单行、细彩色连线和稳定小点；窄面板隐藏日期。打开面板不自动展开详情，单击具体节点才显示一份详情；双击、Enter 或预览按钮才读取完整快照。当前基准回收后显示状态说明，不虚构可预览点。
- 右键或更多提供预览、重命名、从存档继续编辑、移入回收站。重命名 Enter 提交、Esc 取消。回收可撤销，不删除后代、素材或任务固定输入。
- 面板内滚动、名称省略与选中详情适配窄检查器。只有用户点击当前入口或主动创建存档才定位；后台更新不抢选中项、面板或滚动。悬停不解码，反馈可中断，并遵循减少动态效果。

## 保存、预览和采用

Ctrl+S、自动保存和普通 Agent 保存只保存当前编辑。创建存档点才执行 `node.save`。首次默认名称“首次存档”，其后用日期时间；与基准内容相同不重复创建。

预览使用独立只读内容和同一播放器/时间线；全局横幅写明“正在预览存档”，切换面板仍可见。预览中 Ctrl+S 只说明该存档已保存，编辑操作不隐式采用。返回当前编辑或 Esc 恢复原内容、撤销链、选择与播放位置，释放预览资源。

历史时间线允许多选视频、音频、图片、文字及图形并用 Ctrl+C 或右键复制；返回当前编辑后 Ctrl+V 将整组插入当前播放头，保持相对时间。右键“复制到当前编辑”则直接返回原编辑工作区，在进入预览前的播放头插入。复制不采用整个存档、不创建存档，也不自动播放；剪贴板跨预览退出保留，输入框文字复制仍使用原生行为。

整组粘贴一次提交、一次撤销，生成新的片段身份并重映射组内关联，保留历史素材版本、样式和已留存字体。缺失依赖、没有兼容未锁定轨道、同名字体字节冲突、目标切换或并发修改会明确失败，不部分粘贴，剪贴板保留供重试；仅支持回到该存档所属项目的当前编辑。

只有“从这个存档继续编辑”会应用历史。脏编辑先保护为可恢复草稿；通知可撤回，项目菜单可找回之前的编辑。之后创建存档可形成另一条路线，已有后续存档不消失。节点内容、引用身份、revision、CAS、幂等和后台固定目标保持原契约。

存档页“与当前编辑对比”会先返回实际编辑画面，再打开独立只读历史渲染。对比不采用存档，不叠加音频；历史无画面处如实说明，跨项目释放资源。默认画布背景为黑色，显式背景设置优先，GUI、历史和 Agent 不根据界面主题改变成片底色。

## 看板

看板在检查器内使用单列列表和详情，优先显示待用户处理项，已完成默认折叠。添加需求先输入标题与说明，执行约定、引用、验收标准按需展开。原状态、定位、结果查看、比较和严格候选采用链路继续复用；发布不启动 Agent。

直接点击时间线或画布对象回属性；看板定位和 Agent 选择/更新不抢面板。关闭再打开面板、切回项目会保留当前会话的未提交表单。每个项目面板绑定实际编辑 store，旧项目的失焦提交不能写进新项目。历史预览时提示看板仍属于实际编辑目标；定位或应用候选需先返回当前编辑。

## 关闭

标题栏、Alt+F4、菜单退出走同一守卫。先等已接受的工作区事务、草稿写入，再按偏好处理本次会话编辑过且尚未留存的实质内容。纯文字、图形、字幕、动态图形及嵌套实例都属于内容；未编辑旧工程、只读访问、未修改导出副本不自动留存。

“关闭前创建一个存档点？”可选创建存档点并关闭、直接关闭、取消；下次关闭时可选每次询问、自动创建、不创建。取消不提交下次偏好。询问没有自动同意的超时；确认后再次完成待写内容。后台写入失败状态保留并可重试，仍失败就阻止普通关闭；存档失败允许明确重试、仅保存并关闭或取消。强制终止仍只能依靠已完成的草稿落盘。

## 小视口时间线

DockRegion 和轨道父级有界且可收缩。工具栏、标尺固定；轨道在剩余空间纵向滚动，轨道头同步。普通滚轮纵移，Shift+滚轮或横向手势横移，Ctrl/Cmd+滚轮仍缩放。滚动条在可见视口底部，片段边缘拖动继续使用受控自动滚动。

## 修复验收清单

1. Ctrl+S 不创建存档；纯文字可保存和在关闭时创建存档。
2. 节点少、多及未留存试剪都不增加主界面行高；当前入口不造存档。
3. 单击详情、双击只读预览、明确采用互不混淆；全局横幅持续可见。
4. 预览禁止写入，退出恢复编辑内容、撤销、选择和播放位置。
5. 从旧存档继续保护脏编辑，找回/撤回可用，后续历史不消失。
6. 回收当前、中间及预览存档可撤销，不连带删除素材或后代。
7. 重命名不改变身份、父关系或内容；稳定点色不随改名/重开变化。
8. 后台试剪/存档/审片不抢视图，固定目标和并发保护继续有效。
9. 窄检查器、长名称、较多节点、键盘及减少动态效果可用。
10. 关闭等待超过20秒不自退；失败不假成功；候选范围准确。
11. 项目改名在目录、切换通知和复制提示词中一致，无凭据泄露。
12. HEVC 审片通过可用源帧解码进入既有合成器；无解码器时明确失败，真实黑帧仍有效。
13. 已安装字体留存字节；缺失素材/字体明确说明不完整恢复。
14. 至少12条轨道、小视口普通滚轮到达首尾，头部同步、横移/缩放/拖放/播放手势保持。
15. 看板表单不串项目，历史预览期间写入实际目标；中英帮助、导览、CLI schema 和测试包同步。
