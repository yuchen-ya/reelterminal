## 批准的检查器方案

按 [检查器方案](INSPECTOR-VERSIONS-BOARD-UX.md) 实现属性 / 存档 / 看板三个固定页签。状态行仅保留“● 当前”和看板入口；移除主区域横向存档树与看板模态页，存档数量不改变时间线高度。

存档列表较新在上，显示名称、时间及真实父子 SVG 连线；不可变身份决定稳定小点颜色，回收/改名不改变其他点色。当前细环、预览虚线环、已留存试剪菱形各有文字提示。支持支路折叠计数、单击详情、双击/Enter 预览、明确继续编辑、重命名、回收及与当前编辑对比。全局只读预览横幅跨检查器页签保持可见，后台存档不会抢项目或面板。

看板使用单列列表/详情，待处理优先、完成项默认折叠；新需求先填标题/说明，其他字段按需展开。每个项目的表单、滚动和选中状态在当前会话保留，提交绑定实际编辑 store。历史预览期间可查看/提交实际编辑目标的需求，定位或应用候选要求先退出预览。直接点击画布/时间线回属性；看板定位和 Agent 选择不会自动抢页签。

可见 E2E 验证真实独立分支连接到第一份存档、十余记录不增加主时间线行高、跨页签预览/表单保留、跨项目表单隔离、预览期间发布写到实际编辑目标，以及 1024×720 布局。该检查不等同于全部采用/回收/快捷键手势的独立用户验收。

## 小视口多轨滚动

根因是 DockRegion/轨道祖先的 flex 最小尺寸没有约束，轨道内容撑高父级。补充 h-full、min-h-0、min-w-0 和现有轨道滚动容器约束，没有引入另一套滚轮处理。

同一个 1280×720、12 条混合轨道复现：修复前轨道 clientHeight=scrollHeight=780，底边约 1372.67，普通滚轮后 scrollTop=0；修复后 clientHeight=75、scrollHeight=780，底边约 720，普通滚轮到 scrollTop≈704.67。空白、轨道头和片段上的滚轮均到达首尾，头部同步，标尺固定；Ctrl+滚轮缩放、Shift+滚轮横移及播放/暂停仍工作。未穷举所有拖拽/触摸板手势。
