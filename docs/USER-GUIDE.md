# ReelTerminal 用户上手与帮助

用户不需要源码、Node.js 或命令行即可手动剪辑。Windows 安装版安装后打开应用；便携版必须完整解压 ZIP，再运行目录内的 `ReelTerminal.exe`。

1.2.5 本次只提供 Windows x64 包。旧版用户请先阅读[Windows 升级与备份](WINDOWS-UPGRADE.md)：
不要先卸载危险旧版；先备份，保留旧目录，优先在新目录使用 ZIP。ZIP 仍可能读取原有工程数据，并不是独立数据沙盒。

## 本地字幕与音频

选中带声音的视频或音频片段，在右侧检查器的 AI 页签打开本地字幕。
默认 Qwen，语言默认自动；也可指定中文或切换 SenseVoice，两种引擎都通过 Qwen 做词级对齐。
先在“设置”的环境面板确认 Python、模型和音频工具可用；缺少组件时可以复制配置说明交给助手。
安装包不含模型，也不代替你安装 Python 包。当前字幕推理使用 CPU，长素材分段处理；
倒放和变速曲线片段暂不支持。完成后检查文字和时间，一次撤销可移除整批字幕。

音频页签提供静音剪切、节拍同步、降噪和配乐闪避。助手还可调用响度处理、
语音/静音分析、人声分离、匿名说话人分组及同步偏移估计；部分功能需要额外环境。
先用短素材试听。分析不会自动修改时间线，生成的新音频也不会自动替换原素材。
各接口的时长和语种限制见[素材分析](MATERIAL-ANALYSIS.md)。

## 第一次使用

在首页选择“视频编辑器”和画面比例。首次进入编辑器会自动显示可跳过的界面导览，介绍素材、时间线、播放器、检查器、可选智能体协作与导出。导览完成或跳过后不会每次弹出；可以随时通过顶栏“帮助 → 快速开始 → 界面导览”重新打开。

顶栏“帮助”在首页和两个工作区都可用。先读“快速开始”，按新建、导入、剪辑、保存、导出的顺序完成第一条短视频。其余主题可搜索操作名称或快捷键；快捷键显示用户当前设置。

Ctrl+S 和自动保存只保存当前编辑。创建存档点后，可以回看并从这一刻继续剪辑；入口在状态行“● 存档”或左上角项目菜单。右侧默认是属性，底部“存档”和“看板”按需打开面板，关闭返回属性；切换面板不打断剪辑，历史预览横幅仍保留。界面导览专门介绍“存档”入口，详见内置帮助“存档记录”和“保存当前编辑与创建存档点”。
## 随包文档

退出询问会等待你选择，不会因等待超时自动关闭。纯文字等独立内容也可留存；列表只包含本次编辑过的方案，不替未编辑的旧项目或导出副本创建版本。保存失败会保持窗口打开。

安装目录和便携目录内的 `help/USER-GUIDE.zh.html`、`help/USER-GUIDE.en.html` 是可直接用浏览器打开的离线手册，不需要联网。软件内帮助、离线手册和 Agent 的 `help.*` 命令共用 [`gui-manual.ts`](../packages/agent-facade/src/gui-manual.ts) 内容，避免三份说明互相过时。

详细操作步骤维护在该内容源中。本文件说明帮助入口和交付方式，不重复整份手册。

## 外部智能体

先打开项目。命令服务自动可用，默认只读；需要智能体修改项目时在状态栏点击“允许编辑”，完成后可“设为只读”。应用不提供智能体登录或聊天窗口。连接方式见 [外部 Agent 指南](AGENT-GUIDE.md)。手动编辑、保存与导出不依赖 Agent。

## 维护与验收

桌面发行版目前没有配置公开编辑器站点，不提供由本地路由生成的网页分享链接。此类链接的构造入口会明确报“未配置”，不会返回只有 `#/…` 的无效地址；通过分享服务上传后返回的服务端链接不受影响。若未来发行版连接实际托管站点，应明确配置 `publicOrigin` 后再开放该入口。

修改手册时同时更新中文与英文，并确认步骤对应当前界面。`pnpm --filter @reelterminal/desktop build` 会自动生成离线 HTML，打包会把它们放进安装目录的 `help/`。生成的 HTML 不提交 Git。

验收首次启动、跳过与完成后不重复提示、帮助入口、搜索、重新导览、中文/英文切换和离线文件。通过真实桌面确认每一步的目标存在，最后走完导入到导出的实际操作；仅通过类型检查不能证明用户已能完成任务。
