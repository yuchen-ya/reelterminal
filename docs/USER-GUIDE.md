# ReelTerminal 用户上手与帮助

用户不需要源码、Node.js 或命令行即可手动剪辑。Windows 安装版安装后打开应用；便携版必须完整解压 ZIP，再运行目录内的 `ReelTerminal.exe`。

Windows x64 安装包与便携包见[应用发行页面](https://github.com/yuchen-ya/reelterminal/releases)。旧版用户请先阅读[Windows 升级与备份](WINDOWS-UPGRADE.md)：
不要先卸载危险旧版；先备份，保留旧目录，优先在新目录使用 ZIP。ZIP 仍可能读取原有工程数据，并不是独立数据沙盒。

## 项目模板与外部素材

“素材库 → 项目模板”保存和管理本地完整项目快照；使用模板会创建独立新项目，保留当前项目的内容和历史。当前不再提供内置示例模板目录。媒体和字体依赖仍需可用，模板不是包含全部原件的便携备份。左侧“探索更多素材”仅提供分类、搜索和原站链接，不自动下载或导入。

项目菜单另提供“另存工程文件”与“定位已保存文件”（若文件已被移走会明确报错）。本地项目库批量永久删除项目时会一并清理对应的自动恢复槽，保留其他项目及未删除项的恢复记录；“导出与整理”按“选择存档 → 预览清理内容 → 确认执行”的顺序操作，空清理计划在界面与服务层均禁止直接执行。

## 本地字幕与音频

选中带声音的视频或音频片段，在右侧检查器的 AI 页签打开本地字幕。
默认 Qwen，语言默认自动；也可指定中文或切换 SenseVoice，两种引擎都通过 Qwen 做词级对齐。
先在“设置”的环境面板确认 Python、模型和音频工具可用；缺少组件时可以复制配置说明交给助手。
安装包不含模型，也不代替你安装 Python 包。当前字幕推理使用 CPU，长素材分段处理；
倒放和变速曲线片段暂不支持。完成后检查文字和时间，一次撤销可移除整批字幕。

音频页签提供静音剪切、节拍同步、降噪和配乐闪避。恒定速度的片段变速默认保留音高（预览与导出共用 Signalsmith Stretch WASM 处理结果，也可显式关闭保音高使用原生变调变速；变化的变速曲线与冻结帧音频仍不支持保音高，详见 [音频变速说明](AUDIO-SPEED.md)）。助手还可调用响度处理、语音/静音分析、人声分离、匿名说话人分组及同步偏移估计；部分功能需要额外环境。先用短素材试听。分析不会自动修改时间线，生成的新音频也不会自动替换原素材。各接口的时长和语种限制见[素材分析](MATERIAL-ANALYSIS.md)。

## 第一次使用

在首页选择“视频编辑器”和画面比例。首次进入编辑器会自动显示可跳过的界面导览，介绍素材、时间线、播放器、检查器、可选智能体协作与导出。导览完成或跳过后不会每次弹出；可以随时通过顶栏“帮助 → 快速开始 → 界面导览”重新打开。

顶栏“帮助”在首页和两个工作区都可用。先读“快速开始”，按新建、导入、剪辑、保存、导出的顺序完成第一条短视频。其余主题可搜索操作名称或快捷键；快捷键显示用户当前设置。

Ctrl+S 和自动保存只保存当前编辑。创建存档点后，可以回看并从这一刻继续剪辑；入口在状态行“● 存档”或左上角项目菜单。右侧默认是属性，底部“存档”和“看板”按需打开面板，关闭返回属性；切换面板不打断剪辑，历史预览横幅仍保留。界面导览专门介绍“存档”入口，详见内置帮助“存档记录”和“保存当前编辑与创建存档点”。

## 随包文档

退出询问会等待你选择，不会因等待超时自动关闭。纯文字等独立内容也可留存；列表只包含本次编辑过的方案，不替未编辑的旧项目或导出副本创建版本。保存失败会保持窗口打开。

安装目录和便携目录内的 `help/USER-GUIDE.zh.html`、`help/USER-GUIDE.en.html` 是可直接用浏览器打开的离线手册，不需要联网。软件内帮助、离线手册和 Agent 的 `help.*` 命令共用 [`gui-manual.ts`](../packages/agent-facade/src/gui-manual.ts) 内容，避免三份说明互相过时。

详细操作步骤维护在该内容源中。本文件说明帮助入口和交付方式，不重复整份手册。

## 外部智能体

命令服务随应用启动，默认只读。视频项目在状态栏允许编辑。当前文件夹任务的人工决定、草稿和模型密钥不向外部 Agent 开放；内置审阅模型需单独授权任务及来源。点击复制的启动提示词为单行 `start --target <ref>` 命令（固定绑定当前工作区或审阅任务，不含凭据），Agent 随后通过 `tools` 与 `describe` 按需发现能力与命令契约。应用不提供智能体登录或聊天窗口。连接方式见 [外部 Agent 指南](AGENT-GUIDE.md)。手动编辑、保存与导出不依赖 Agent。

## 审阅工作台与自由画板

从“审阅工作台”打开已有任务文件夹，或新建任务。标签栏可切换文件夹和自由画板；关闭标签不删除内容。文件管理中的移动、复制和重命名作用于真实文件，复制不是审阅决定。

从文件夹进入任务工作台，设置目标，逐项查看原文、图片、视频帧或局部区域，记录人工决定与批注。草稿与决定留在任务文件夹的 .reelterminal 中。需要模型建议时先配置端点与密钥，再明确授权任务/来源；不使用模型也可手动审阅。MobileSAM 区域分割在本地 CPU 执行。

保存结果不确定时保留输入并暂停相关写入。先核对本次决定：已保存无需重复提交，确认未提交后才可显式重试。导出前预览选择和判定范围，只有明确批准的内容可作为审阅结果；含混合判定的原文件会单独披露。

实验性的独立批次审阅已退役，不再提供新建、打开、标签恢复或旧命令入口；已有数据不会自动删除或迁移。请用原件创建真实文件夹任务。已打开的视频工程可从“打开 / 管理”右侧的管理菜单进入原项目工作台，与新文件夹任务分开使用。当前工作台与视频编辑的联动仍有限。自由画板用于私人图文整理、文档浏览、视频/模型观察和区域 PNG 截图；只有用户明确导出的快照才会成为交付内容。详见[审阅工作台说明](../README_review.md)和[自由画板使用说明](HUMAN-BOARDS.zh-CN.md)。

## 网页分享

桌面发行版目前没有配置公开编辑器站点，不提供由本地路由生成的网页分享链接。此类链接的构造入口会明确报“未配置”，不会返回只有 `#/…` 的无效地址；通过分享服务上传后返回的服务端链接不受影响。若未来发行版连接实际托管站点，应明确配置 `publicOrigin` 后再开放该入口。
