# ReelTerminal 用户上手与帮助

用户不需要源码、Node.js 或命令行即可手动剪辑。Windows 安装版安装后打开应用；便携版必须完整解压 ZIP，再运行目录内的 `ReelTerminal.exe`。

1.3.3 当前构建面向 Windows x64；本地打包与公开发布状态见[版本说明](RELEASE-1.3.3.md)。旧版用户请先阅读[Windows 升级与备份](WINDOWS-UPGRADE.md)：
不要先卸载危险旧版；先备份，保留旧目录，优先在新目录使用 ZIP。ZIP 仍可能读取原有工程数据，并不是独立数据沙盒。

## 项目模板与外部素材

“素材库 → 项目模板”保存和管理本地完整项目快照；使用模板会创建独立新项目，保留当前项目的内容和历史。当前不再提供内置示例模板目录。媒体和字体依赖仍需可用，模板不是包含全部原件的便携备份。左侧“探索更多素材”仅提供分类、搜索和原站链接，不自动下载或导入。

## 本地字幕与音频

选中带声音的视频或音频片段，在右侧检查器的 AI 页签打开本地字幕。
默认 Qwen，语言默认自动；也可指定中文或切换 SenseVoice，两种引擎都通过 Qwen 做词级对齐。
先在“设置”的环境面板确认 Python、模型和音频工具可用；缺少组件时可以复制配置说明交给助手。
安装包不含模型，也不代替你安装 Python 包。当前字幕推理使用 CPU，长素材分段处理；
倒放和变速曲线片段暂不支持。完成后检查文字和时间，一次撤销可移除整批字幕。

音频页签提供静音剪切、节拍同步、降噪和配乐闪避。助手还可调用响度处理、
语音/静音分析、人声分离、匿名说话人分组及同步偏移估计；部分功能需要额外环境。
先用短素材试听。分析不会自动修改时间线，生成的新音频也不会自动替换原素材。
各接口的时长和语种限制见[素材分析](MATERIAL-ANALYSIS.md)。

## 第一次使用

在首页选择“视频编辑器”和画面比例。首次进入编辑器会自动显示可跳过的界面导览，介绍素材、时间线、播放器、检查器、可选智能体协作与导出。导览完成或跳过后不会每次弹出；可以随时通过顶栏“帮助 → 快速开始 → 界面导览”重新打开。

顶栏“帮助”在首页和两个工作区都可用。先读“快速开始”，按新建、导入、剪辑、保存、导出的顺序完成第一条短视频。其余主题可搜索操作名称或快捷键；快捷键显示用户当前设置。

Ctrl+S 和自动保存只保存当前编辑。创建存档点后，可以回看并从这一刻继续剪辑；入口在状态行“● 存档”或左上角项目菜单。右侧默认是属性，底部“存档”和“看板”按需打开面板，关闭返回属性；切换面板不打断剪辑，历史预览横幅仍保留。界面导览专门介绍“存档”入口，详见内置帮助“存档记录”和“保存当前编辑与创建存档点”。
## 随包文档

退出询问会等待你选择，不会因等待超时自动关闭。纯文字等独立内容也可留存；列表只包含本次编辑过的方案，不替未编辑的旧项目或导出副本创建版本。保存失败会保持窗口打开。

安装目录和便携目录内的 `help/USER-GUIDE.zh.html`、`help/USER-GUIDE.en.html` 是可直接用浏览器打开的离线手册，不需要联网。软件内帮助、离线手册和 Agent 的 `help.*` 命令共用 [`gui-manual.ts`](../packages/agent-facade/src/gui-manual.ts) 内容，避免三份说明互相过时。

详细操作步骤维护在该内容源中。本文件说明帮助入口和交付方式，不重复整份手册。

## 外部智能体

命令服务随应用启动，默认只读。视频项目在状态栏允许编辑；审阅工作台另有独立的 Agent 编辑开关，可复制当前安装的接入说明。应用不提供智能体登录或聊天窗口。连接方式见 [外部 Agent 指南](AGENT-GUIDE.md)。手动编辑、保存与导出不依赖 Agent。

## 审阅工作台

顶栏有“视频编辑 / 审阅工作台”两个主入口；旧 Motion 工具在次级入口。审阅工作台不需要视频项目。先创建数据节点，再导入文件、文件夹、粘贴文本或 CSV/JSON 数据；Agent 也可用 `review.ingest` 提交批次。节点侧栏支持最近、置顶、单层分组、搜索、归档和回收站；节点内的批次队列用于逐项审阅，正文与步骤列表按页读取。

任务对应独立目标，Agent 持续在指定任务中提交，新增批次、试做或返工不另建任务。分组是组织树的父节点，可按类型、批次、工作阶段等组织；按自身及子项最新修改时间排序，备注仅在有内容时显示。新建任务分支已停用，现有历史关联可从任务菜单查看。

分组名称打开统一集合视图，箭头负责展开或折叠。集合支持单击选择、Ctrl/Cmd 多选、Shift 连选和双击进入单项；返回保留选择、预览方式和滚动位置。图片完整显示，另可切换实际像素或整数倍像素预览。“未分组”不表示共同谱系父节点。Agent 可设置 groupMode 为 board 或 category，并让返工视频的 compareWithItemId 指向同批基准视频。预绑定对比条目不会自动建立视频时钟映射。节点标题建议 4–8 个汉字或不超过 15 字符，不重复批次名前缀。

选中项与本组待审项分别操作；待审为零时按钮禁用。父节点右键和更多菜单支持共同要求批量返工、恢复待审和导出；覆盖已有审核结论前显示范围确认，批量操作一次撤销。分页范围明确标为本页；菜单数量是实际作用项数，常规操作针对各条目的当前版本，不遍历历史版本。

文本默认按 Markdown 渲染标题、列表、表格、引用和代码块。“直接改文”使用 @uiw/react-md-editor 的轻量编辑器与实时预览；“原文与批注”提供精确字符区间批注，已有批注仍绑定原版本。保存保留 Markdown 原文并创建新版本，不把渲染结果写回文本。

图片、语料、数据和视频复用各自审阅工具。保留、丢弃、标为待返工均可撤销；丢弃不删除源文件，保留不自动加入时间线。图片修补、改文和单元格修改保存新版本。“交回本轮决策”发布已决定条目的不可变快照，草稿反馈不会发送；等待 Agent 真实读取和确认后才更新交接状态。返工只重新打开对应条目。

“处理过程”展示实际记录的输入、输出、方法、参数、候选分支和失败；缺记录明确显示未记录。可固定两个版本比较：图片并排/滑杆、文字差异、按稳定行列标识的数据差异，以及有明确时间映射的视频同步对比。无映射时独立查看。每个步骤引用可直接导出精确版本，区域标记不会暗中裁剪文件。

条目与分组可直接拖出，分别交付文件与分组命名的文件夹，默认使用当前已保存版本。若尚未准备好，会显示进度，完成后再次拖出或选择保存位置。

导出对话框可选择初始原件、当前已保存版本、人工采用版本或完整节点包，再明确整个节点、当前筛选或选中范围。准备完成后可保存副本，或将文件/文件夹手柄拖入 Explorer。系统开始拖拽不等于目标已收到；移动、删除导出副本不改变节点原件。节点包含保留版本、步骤与历史资源，可从文件夹校验恢复；历史交接不可继续执行。缺文件或旧正文会明确提示，不能把这样的包当完整备份。“备份全部节点”包含归档和回收站节点及目录索引，目前按节点恢复。

“添加采用版本到项目”把人工采用的图片/视频独立复制到明确选定的视频项目和工作区，不添加时间线片段。项目撤销导入不会删除审阅原件。重命名只改显示名；永久清空回收站节点前会检查引用，并要求同时确认删除该节点全部历史。其他节点引用和项目副本保持，物理文件在孤儿宽限期后、后续启动时回收，不立即释放空间。

旧项目工作台可从次级项目入口访问，也可用“迁移项目工作台”先预览再确认。可读媒体复制为独立文件，缺失文件和旧版本正文保留明确标记；原工作台成为只读备份。旧 workbench 撤销组会移除，其他工程撤销保留，重做分支在这次新编辑边界清空。保存中断可重复执行，不重复导入；旧应用仍可能修改备份，下次迁移须预览并追加新批次。不要用旧应用编辑迁移过的备份。命令说明见 [COMMAND-API.md](COMMAND-API.md#independent-review-workspace)。

## 维护与验收

桌面发行版目前没有配置公开编辑器站点，不提供由本地路由生成的网页分享链接。此类链接的构造入口会明确报“未配置”，不会返回只有 `#/…` 的无效地址；通过分享服务上传后返回的服务端链接不受影响。若未来发行版连接实际托管站点，应明确配置 `publicOrigin` 后再开放该入口。

修改手册时同时更新中文与英文，并确认步骤对应当前界面。`pnpm --filter @reelterminal/desktop build` 会自动生成离线 HTML，打包会把它们放进安装目录的 `help/`。生成的 HTML 不提交 Git。

验收首次启动、跳过与完成后不重复提示、帮助入口、搜索、重新导览、中文/英文切换和离线文件。通过真实桌面确认每一步的目标存在，最后走完导入到导出的实际操作；仅通过类型检查不能证明用户已能完成任务。
