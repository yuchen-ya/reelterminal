# 自由画板

在桌面版的审阅工作台顶部统一标签栏中新建或打开「自由画板」。审阅任务与自由画板共用
同一条可排序标签栏，支持拖拽调整顺序、关闭标签保留实体并在重启后恢复；通过标签栏的
「打开 / 管理」对话框集中管理已保存画板与任务分类。画板固定为纯白背景（`#FFFFFF`），
不跟随应用深色主题变暗。

自由画板独立保存，不创建隐藏审阅节点，也不进入 Agent 的上下文、变更列表、交接或审阅
修补 CLI。当切换到自由画板标签时，地址栏明确显示当前为私有画板、无 Agent 目标；只有
用户主动导出的单个内容快照会成为正规的审阅节点。

## 创建和添加内容

- 在「空白入口 · 拖入或粘贴」拖入文件、粘贴图片或文字，会自动创建画板标签页。
  文件导入使用首个文件名命名，文字粘贴使用首行命名；顶部名称可以直接修改，关闭标签页时未保存的名称修改会自动落盘。
- 同一次导入的图片、视频、GLB、文本、Markdown 和 HTML 文件放在同一张
  画板。文本文件支持 `.txt`、`.log`；Markdown 支持 `.md`；HTML 支持
  `.html`、`.htm`。单独的 HTTP/S 链接会成为网页容器，含链接的普通段落仍为文字。
- 在已有画板拖入文件，内容放到落点；「导入文件」或粘贴追加的批次会放到
  现有内容下方，避免盖住旧对象。通过顶部标签栏切换不同画板或审阅任务；在「打开 / 管理」对话框中可打开、重命名或删除已保存的画板。
- 在审阅图片视图点击「加入自由画板」，会创建并打开一张包含该图片的新自由画板标签页。已有修补版本优先作为图片来源。

使用画板原生工具进行文字、箭头、自由笔、移动、缩放、多选、复制、组合及
层级调整。选中图片后还可使用「裁剪图片」「旋转 90°」和翻转。
`Shift+1` 可以适应全部内容。

视频支持原生播放控件、秒数定位及「截取当前帧」；GLB 支持旋转、平移、
缩放和「截取当前视角」。截帧、视角截图均作为独立图片加入当前画板。

Markdown 默认使用现有 Markdown 预览器显示标题、表格、代码和经过净化的
HTML 内容；「编辑源码」进入原文编辑，保存才提交一次画板编辑，取消保留原文。
导入时只保留文档目录内实际引用的文件和受管映射，不扫描复制整个目录；
缺失、越界或非法编码引用会列明而不会中断渲染。相对 Markdown 链接打开新文档容器，HTTP/S 链接建立
网页容器。已保留的引用在原目录移走后仍可使用。单条文档最多 2 MiB、200000
字符，引用最多 256 项、合计 32 MiB。源码编辑继续使用导入时保留的资产；
新增磁盘引用需要重新导入。

本地 HTML 导入时使用 Electron 自带的 Chromium 内容视图生成首屏 PNG；
生成时短暂显示固定预览区域，完成后回到画板快照。
自动预览仅加载本地受管资产，不自动访问网络。保存 HTML 源码会生成新的首屏
快照，并与源码一起提交。网页链接首次显示 URL，点击「进入浏览」才加载。
浏览时使用固定区域的现成内容视图，页面滚动、链接和表单由 Chromium 处理；
没有自制 HTML 渲染器、导航栏或多标签管理器。普通页面 JavaScript 可以执行；
该视图没有 Node 或应用 preload，
本地文件访问限定为保留资产，页面权限和下载均不开放。区域截图和网页浏览期间暂时锁定顶部工作区标签切换。

「截图当前视口并返回画板」更新容器的受管视口快照；「返回画板」只结束浏览。
HTML 和网页在画板上展示快照，不是可任意旋转层叠的多个实时网页。
网页保存 URL 与已有视口，离线时仍可看已保存快照；不代表保存了完整离线网页。

## 图片修补与局部新图

选中图片，点击「像素修补」进入源像素编辑。可使用画笔、橡皮、仿制图章和
外部贴片。仿制图章用 `Alt` + 单击设置取样点；外部贴片导入后在目标位置
单击放置。保存后，画板中的裁剪、旋转和翻转仍然保留。

修补窗口内的按钮、快捷键和应用菜单撤销/重做都作用于当前修补草稿。
保存后的整次修补可以通过画板撤销；普通画板编辑使用 Excalidraw 自身的
会话内历史，自动保存不会额外增加撤销步骤。

需要把图片的局部单独保留时，可先裁剪，再点击「单个文件：拖出 / 保存」，
在输出中选择「作为新图加入画板」。原件资源保持不变。

## 区域截图、复制和原生拖出

截图可选择矩形、多边形或自由选区；多边形闭合后可拖动顶点调整。可勾选透明背景，按 Enter 生成、Escape 取消；切换选区模式或重置会清除当前选区。画布中拖动物体仅用于移动布局；系统文件拖出请使用输出面板的「拖出文件」按钮。

「区域截图」使用专门的框选层，不改变对象多选。进入时会冻结当前视口中的
场景、视频帧、模型视角、Markdown 可见预览及已有 HTML/网页视口；网页尚未
截图时会明确要求先浏览截图。需要更大的范围时，先移动或缩放画布。

拖动框选后点击「生成 PNG」。PNG 包含源图片、文字和绘图标注，不包含
编辑控件，并保持白底。图片、文字和绘图从源内容渲染；Markdown 使用真实
渲染后的正文视口截图，HTML/网页使用 Chromium 捕获的已保存视口。
图片按源像素输出；3D 视角从场景以 1920 像素宽重新渲染。单边超过 16384
像素或面积超过 64MP 时，需要缩小截图区域。

输出面板提供：

- 「拖出文件」：文件准备就绪后，直接拖到资源管理器或其他接收文件的应用。
  「已交给系统拖动」表示系统接手拖动；是否接收以目标程序的结果为准。
- 「复制」：图片写入系统 PNG 剪贴板，文本写入文本剪贴板。
- 「保存到…」：选择目标文件夹保存。
- 「作为新图加入画板」：将冻结的 PNG 作为独立图片追加。

选中单个内容后，「单个文件：拖出 / 保存」提供相同的文件输出入口。
单图片输出保留图片自身透明度，包含当前裁剪、旋转、翻转和修补；
视频和模型输出其原类型文件。

截图、复制、保存和拖出都不会自动创建审阅节点或向 Agent 交接。

## 主动导出单个审阅快照

只选中一个内容容器，点击
「导出此内容为审阅节点」。文字导出正文，图片导出当前处理后的 PNG，
视频和模型保留原类型。生成的节点是独立内容快照，之后修改画板不会改变它。
可点击「打开导出的审阅节点」在标签栏打开该节点继续审阅。

Markdown 明确选择「正文 → text」或「可见预览 PNG → image」；HTML 和网页
默认选择「当前视口 PNG → image」，也可显式选择 HTML 源码或 URL 文本。
单个文件的保存、复制和原生拖出使用同一选择，不会隐式更换内容类型。

画板自动保存，关闭标签页保留画板实体，并在重开或应用重启时恢复内容和视口。在「打开 / 管理」对话框中删除画板会删除该板及其私有
资源保留记录；已导出的审阅快照及仍被其他内容引用的资源会继续保留。
