# 人工画板

在桌面版的审阅工作台顶部选择「人工画板」。画板固定为纯白背景
（`#FFFFFF`），不跟随应用深色主题变暗。

人工画板独立保存，不创建隐藏审阅节点，也不进入 Agent 的上下文、
变更列表、交接或审阅修补 CLI。只有用户主动导出的单个内容快照会成为
正规的审阅节点。

## 创建和添加内容

- 在「空白入口 · 拖入或粘贴」拖入文件、粘贴图片或文字，会自动创建画板。
  文件导入使用首个文件名命名，文字粘贴使用首行命名；顶部名称可以直接修改。
- 同一次导入的图片、视频、GLB 和文本文件放在同一张画板。文本文件支持
  `.txt`、`.md`、`.log`。
- 在已有画板拖入文件，内容放到落点；「导入文件」或粘贴追加的批次会放到
  现有内容下方，避免盖住旧对象。左侧列表可切换画板。
- 在审阅图片视图点击「加入人工画板」，会加入当前人工画板；没有打开画板时
  会创建一张新板。已有修补版本优先作为图片来源。

使用画板原生工具进行文字、箭头、自由笔、移动、缩放、多选、复制、组合及
层级调整。选中图片后还可使用「裁剪图片」「旋转 90°」和翻转。
`Shift+1` 可以适应全部内容。

视频支持原生播放控件、秒数定位及「截取当前帧」；GLB 支持旋转、平移、
缩放和「截取当前视角」。截帧、视角截图均作为独立图片加入当前画板。

## 图片修补与局部新图

选中图片，点击「像素修补」进入源像素编辑。可使用画笔、橡皮、仿制图章和
外部贴片。仿制图章用 `Alt` + 单击设置取样点；外部贴片导入后在目标位置
单击放置。保存后，画板中的裁剪、旋转和翻转仍然保留。

修补窗口内的按钮、快捷键和应用菜单撤销/重做都作用于当前修补草稿。
保存后的整次修补可以通过画板撤销；普通画板编辑使用 Excalidraw 自身的
会话内历史，自动保存不会额外增加撤销步骤。

需要把图片的局部单独保留时，可先裁剪，再点击「单个文件：拖出 / 保存」，
在输出中选择「作为新图加入画板」。原件资源保持不变。

## 区域截图、复制和原生拖出

「区域截图」使用专门的框选层，不改变对象多选。进入时会冻结当前视口中的
场景、视频帧和模型视角；需要更大的范围时，先移动或缩放画布。

拖动框选后点击「生成 PNG」。PNG 包含源图片、文字和绘图标注，不包含
编辑控件，并保持白底。它从源内容渲染，不截取低分辨率的屏幕画面。
图片按源像素输出；3D 视角从场景以 1920 像素宽重新渲染。单边超过 16384
像素或面积超过 64MP 时，需要缩小截图区域。

输出面板提供：

- 「拖出文件」：文件准备就绪后，直接拖到资源管理器或其他接收文件的应用。
  「已交给系统拖动」表示系统接手拖动；是否接收以目标程序的结果为准。
- 「复制」：图片写入系统 PNG 剪贴板，文本写入文本剪贴板。
- 「保存到…」：选择目标文件夹保存。
- 「作为新图加入画板」：将冻结的 PNG 作为独立图片追加。

选中单个内容后，「单个文件：拖出 / 保存」提供相同的文件输出入口。
单图片输出保留图片自身透明度，包含当前裁剪、旋转、翻转和修补；
视频和模型输出其原类型文件。

截图、复制、保存和拖出都不会自动创建审阅节点或向 Agent 交接。

## 主动导出单个审阅快照

只选中一个文本、图片、视频或模型内容容器，点击
「导出此内容为审阅节点」。文字导出正文，图片导出当前处理后的 PNG，
视频和模型保留原类型。生成的节点是独立内容快照，之后修改画板不会改变它。
可点击「打开导出的审阅节点」继续审阅。

画板自动保存，并在重开时恢复内容和视口。左侧删除画板会删除该板及其私有
资源保留记录；已导出的审阅快照及仍被其他内容引用的资源会继续保留。
