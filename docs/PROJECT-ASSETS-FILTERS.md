# 项目素材：类型筛选、存档关联与字幕导入

## 交互

项目素材采用“轻量入口”布局：

- 常驻一排：全部、视频、音频、图片、字幕。标题和导入合并为一行；录制、缩略图/列表切换和保存时间线选区位于“更多”。
- **按存档查找**：按需展开本项目未回收的节点树，显示父子层级。选中后收起树，以可关闭的“存档：名称”提示当前范围。关闭提示返回当前项目素材；历史预览时标明只读预览。
- **筛选**：原片、保存的剪辑和组合收进次级弹层，不再多占一排分类。保存的剪辑按来源媒体类型筛选；组合可匹配任一成员类型。
- **排序**：数量右侧提供最新/最早添加、名称正反序、时长长短序。原始媒体使用项目中的导入顺序；剪辑和组合使用保存时间。图片或无有效时长的媒体始终排在时长排序末尾。原始媒体与保存剪辑分组内排序，字幕列表按同一选择排列。
- 点击媒体可查看关联存档，点击关联节点直接筛选。关联来自存档摘要中的媒体 ID，无需加载所有历史项目。

搜索、类型、素材形式、节点和排序组合使用。切换类型或节点保留排序；清除筛选也保留排序。
来源及候选状态仍可在制作记录编辑器中维护，但不再占据主筛选入口。

存档树的详情区及右键菜单都提供“查看此节点素材”。该操作只改变素材面板的范围，
不激活历史预览、不采用节点，也不改动当前工程。
选择节点时按需读取这一份快照，包含已从当前编辑移除、但仍保留在节点中的媒体。
节点素材只读，标明“时间线使用”或“节点保留 · 未放入时间线”，可勾选仅查看时间线使用项。
此处的“使用”指该节点时间线片段的直接媒体引用；不是全工程依赖或垃圾回收判定。
历史范围中的媒体不提供删除、重命名或直接拖入当前编辑的操作。

切换工程会清除范围、类型和搜索，避免上一项目的筛选残留。
较早的异步节点读取完成后不能覆盖已选的新节点。

## 字幕

项目素材的主“导入”按钮与拖放入口支持 `.srt` / `.vtt`，复用已有字幕解析器，
支持 UTF-8/BOM、CRLF 及 VTT 时间码。字幕按文件中的绝对时间码创建在 Captions 文字轨，
不是放入音视频解码管线，也不按播放头自动偏移。

- 整个文件作为一次批量操作提交，一次撤销撤回本次导入。
- 导入成功切到“字幕”类型，列表显示时间码与内容；在时间线上编辑字幕。
- 文件没有有效字幕时明确报错，不修改工程；部分段落无效时导入有效内容并提示警告。
- 文件读取期间切换工程或进入只读预览会停止导入；提交前再次检查目标状态。
- 拖放时立即复制文件列表，避免浏览器在异步读取文件句柄期间清空拖放数据。

本次没有增加 ASS/SSA 格式解析或非 UTF-8 编码转换。

## 1.1.2 录制修复

桌面编辑页与网页工具栏共享录制弹窗和导入处理。Windows 的屏幕/窗口列表由 Electron 原生菜单提供，必须明确选择后才开始；支持系统选择器的平台使用系统选择器。取消选择会返回录制错误提示。
停止按钮与系统停止共享都交付录制结果；关闭弹窗释放流，避免旧结果在下一次录制时重复导入。
`e2e/screen-recording.e2e.ts` 使用合成画面验证实际 MediaRecorder 编码、暂停/继续、连续两次录制及导入，不录制用户桌面或麦克风。真实采集设备不在该自动化验收范围内。
