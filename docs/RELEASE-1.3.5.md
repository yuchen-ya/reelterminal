# ReelTerminal 1.3.5

日期：2026-10-27（Asia/Shanghai）。Windows x64 本地构建。

## 交互变化

- 任务管理集中到最左侧。任务卡片提供右键及可见的“…”菜单，包含重命名、分类、置顶、归档、复制接入说明和历史关联。顶部任务名仅用于定位；底部提供回收站入口。
- 移到回收站先显示任务名称及影响范围，默认聚焦取消；取消不修改目录，确认操作绑定原任务及目录修订。永久删除沿用原有引用检查及二次确认。
- 第二栏保留当前批次的内容树。批次切换器独占紧凑的一行，NEW 位于按钮内的名称右侧、箭头左侧，不显示上下小字或底部说明。导入及筛选等工具与批次名称分行。
- Agent 新增条目、新建批次或提交新内容版本时产生未查看更新提示；人工编辑、审阅决定及备注不会产生 NEW。批次按最近内容更新时间排序；新内容到达不切换当前批次。
- 批次、条目与任务的查看进度保存在本地显示状态，独立于审阅决定及撤销历史。进入批次消除批次提示，未查看条目保留标记；升级前的已有内容不会全部被标为 NEW。

本次提交也包含此前已交付的 1.3.2–1.3.4 源码修改，详见对应版本说明。
