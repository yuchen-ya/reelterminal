# 任务队列与验收

依据：[方案](PLAN.md)。调度及任务卡格式见[执行规程](EXECUTION.md)。

本表是任务模板，不是已完成记录。每次执行由子代理先核实文件位置，再把模板实例化为精确任务卡。
下列“范围”是调查起点，不能直接当作无限写入授权。跨出任务卡文件范围须由主会话重新分配锁并确认仍在方案内。
每行建议时间盒 30–90 分钟；到时保留证据并拆分/阻塞，不为赶时间降低验收。

## F. 不依赖主阻塞项的后备队列

F01 核对当前文档内部链接；F02 核对中英文新增 key 与回退；F03 核对配置示例和实际默认值；
F04 核对错误状态是否存在无限等待；F05 核对 package/script 文档；F06 审查最终 diff 的无关修改；
F07 补充已确认缺陷的最小复现；F08 核对已知限制的证据；F09 检查现有测试是否覆盖本轮回归风险；
F10 根据固定候选生成可执行的人工验收步骤。

每项只能在有新对象或新证据时执行。已完成无变化的项目不重复扫描，不为保持运行而添加测试、注释或重构。

## 调度建议

首批 A01→A02/A05/B04 的调查，A03 与 B01 小改动作为试运行；随后优先浏览器阻断与桌面严重问题。
每批不超过 3 个实现任务，再进行独立审查与同步；D01/D03 尽早进入，不全部留到最后。
表中依赖表示相关结果必须可用，局部阻塞不阻止没有依赖的任务。
