# 真人验收修复任务卡

依据：[GUI-PLAN.md](GUI-PLAN.md)。所有任务初始为 pending；执行事实记录在仓库外，不能靠修改本文状态充当证据。
调度者派发时补全冻结基线、精确文件权限、命令与报告路径；角色/锁/原改动保护遵守 EXECUTION.md。

## 通用验收与拆分

- 源问题编号保持不变，子卡使用下列 G 编号；每个实现卡必须有不同代理验收。
- 一卡超过可审查规模，按操作或能力拆分子卡；保持父卡未完成，不能把剩余内容移出范围。
- 数据/编辑操作验证失败回滚、撤销重做、保存重开、重复请求、错误输入；界面小改不机械新增镜像测试。
- Agent 能力使用 live 桌面验证真实 store 和 GUI 变化；GUI 路径另行用 computer use 实测，互相不能替代。

## 基础与契约

### G00 — 基线与执行试运行

保护当前 HEAD、status、原改动指纹及私有备份，继承上一轮手册和已知限制。记录实际构建/进程版本，不能假设还是 471bcb9。
检查子代理、模型、GUI 工具、两款应用、live 连接和可用本地外部能力；不安装服务或购买额度。
输出：运行账本、原改动排除表、工具可用矩阵、首个小任务独立验收闭环。

### G01 — 共享契约调查与设计

依赖 G00。调查项目媒体、片段模型、历史、库 GC、预设与会话状态；为 G07–G14 输出可实施的字段/操作/兼容性设计。
明确项目级/用户级数据边界、媒体引用存活判定、撤销与任务状态边界；复用现有机制的证据具体到函数。
验收：独立审查旧项目加载、失联引用、删除/撤销和幂等流程。只读调查可与基础修复并行。

## 基础体验

### G02 — 时间线适配（#1）

增加可见适配入口，修复长项目缩放下限，统一标尺与缩放控件。
验收：空项目、30 秒、8 分钟、1 小时；可见全部内容；缩放后拖拽/定位不偏移；普通剪辑/撤销不突然改变视图；关闭重开符合记录策略。

### G03 — 项目改名与快捷键可发现性（#2）

明显改名入口；可点击快捷键说明入口；复用已有命名和快捷键数据，不增加重映射系统。
验收：只靠鼠标能找到两者；长中文名、取消、提交、重开；输入框焦点不误触快捷键；Windows 标示 Ctrl。

### G04 — 浮层与交互层级（#3）

复现说明浮层遮挡，检查真实 stacking context；修复并检查项目菜单、右键菜单、教程、拖拽、对话框、toast。
验收：不同窗口尺寸下无裁切/覆盖；Esc、外点关闭、焦点恢复正确；拖拽和播放头不被错误遮罩阻断。
禁止仅把数值改得更大就结束；共性存在才提取层级规则。

### G05 — 视频轨静音/独奏（#4）

将现有控制接到视频轨头，区分声音与画面状态。
验收：两视频轨+音频轨含可辨声音，逐一 mute/solo；试听和导出一致；撤销恢复；无声视频表现不误导。

### G06 — 翻译与能力说明（#11、#5 文案）

补字幕功能区及普查确认遗漏，清理把非文案传给 t() 的真实案例。
验收：中英文逐界面浏览；静态检查排除误报，新增确定缺漏可定位；不自动翻译 SVG/path 等字符串。
依赖各新功能文案逐批追加，末批再次汇总。

## 原生功能与 Agent 对等

### G07 — 本地/云功能逐项复核（#5）

读取原 ai-features-audit.md 并现场复核，建立全部本地功能和云入口清单。
核对 kill-switch 构建配置和遗漏；完善不可用/失败说明；为每个本地功能生成 G07-<能力> 实现与验收子卡。
覆盖静音剪切、节拍同步/自动编辑、降噪/对白、闪避、色键、自动调色、MediaPipe 抠像/Behind Subject、跟踪、Whisper 字幕、shader 放大；现场发现计数不同按事实列出。
子卡交付 GUI 真实结果及 Agent 可调用的同一能力；已有能力做 verified-no-change，缺失补接线，不新建重复算法。
Auto Reframe 单独子卡：接通真实主体构图/裁切路径，移动主体样本验证结果，不接受假进度。
验收：关云零请求；失败不成功提示；模型初次下载/缺失状态明确；异步任务取消不留下半编辑；输出真实变化且可撤销、导出。

### G08 — 项目媒体显示名（#6a）

依赖 G01。GUI 改名与 Agent 编辑操作共用模型；保留源文件名/路径，不改真实文件名。
验收：同名素材可区分 ID；搜索/面板一致；中文、空名校验；历史与重开；旧项目默认名字兼容。

### G09 — SVG 与字体摄取（#7）

依赖 G01。拆 SVG 和字体两子卡，复用已有 GUI 能力与校验，补 Agent 输入路径。
验收：SVG 进入可编辑内容，保存/重开/导出；非法或外联 SVG 明确拒绝；字体在新文字与重开后可用，缺字体有明确降级；文件读取遵守 live 根目录规则。
测试仅用明确可用的示例字体，不批量安装系统字体或下载无来源字体包。

### G10 — HTML/CSS 生成图像（#7）

依赖 G09 或独立完成摄取调查。复用宿主渲染设施，提供受限工件生成路径。
验收：透明背景、尺寸、资源缺失、超时、取消；拒绝远程加载/任意脚本及越界文件；产物经普通媒体通道进入项目并导出。

## 工作素材与预设

### G11 — 项目内工作素材（#6b）

依赖 G01/G08。分四卡：持久模型与引用保护；单片段捕捉/实例化；多片段相对布局捕捉/展开；GUI 与 Agent 联通。
入口称“保存到工作素材”，与个人素材库区分；支持命名、搜索、删除、重用，Agent 用稳定 ID 操作。
验收：修剪+变速+效果捕捉，删原时间线片段后仍能复用；实例修改不改原件；多片段时序不变；重复请求不重复上轨；保存重开、撤销、缺媒体说明、GC 不误删有效引用。

### G12 — 自定义预设（#9）

依赖 G01，图形子卡依赖 G09。分基础存储/校验、文字、图形、效果、转场、管理与 Agent 子卡。
面板合并内置和自定义；创建/改名/删除/应用；内置只读；预设内容与项目实例隔离。
验收：GUI 保存后 Agent 查询，Agent 创建后面板立即可见；跨项目重开；应用效果与预览一致；缺字体/素材可理解；未知参数拒绝；删除预设不损坏已经应用的项目。
引用计入资源存活设计；不得因用户级预设暂未打开而回收其字节。

### G13 — 配音与音乐入口（#8）

依赖 G01。分现有 live 链路实证、会话任务契约、GUI 表单与状态、产物接收/重试四卡。
复用外部 Agent；TTS 和音乐均有入口。先用当前已配置能力和合成文本完成真实生成，未配置 provider 不自动安装或付费。
验收：成功试听/入轨；无 Agent、外部失败、取消、重试、应用重开、结果重复、切换项目；任务与产物关联真实，不承诺不可能的“同参数必定相同输出”。
若无外部生成能力，协议及失败路径可验，但成功路径保持 blocked，不能用测试音频冒充真实生成成功。

### G14 — GUI 说明书（#10）

界面变更稳定后完成。依赖 G03 共享快捷键数据；覆盖前述全部新入口。
分结构化内容/版本、查询接口、关键截图/打包三卡。
验收：从外部 Agent 在不读取源码的前提下查到改名、静音、工作素材、预设与配音入口；语言/版本正确；截图资源在打包后仍可访问；不可用章节不编造说明。

## 同步与最终验证

### G15 — 专职文档代理

逐批维护实际产品指南、协议/能力表、外联说明、工作素材与预设区别、说明书索引。纠正旧 F08 中已经解决的 C08 状态，保留历史事故记录。
新工具计数从最终注册事实计算。不得把执行过程任务号写进用户手册。独立输出最终同步结论。

### G16 — 专职注释代理

与 G15 不同代理。核对存储引用、事务、取消、幂等、异步回调与能力边界的注释，清理新增内部任务号和过时契约。
不以注释数量为目标；冻结后复核最终差异，不能凭前批清零结论过关。

### G17 — 集成与冻结

定向检查通过后运行受影响包 typecheck/test/build，核对 adapters、桌面打包资源和新协议导出。
记录 HEAD + 原修改 + 本轮未提交差异/指纹 + 实际运行构建。原修改未提交时不能声称验证了“纯提交候选”。
已有 flaky 测试独立登记，不让它掩盖新失败；只复跑有归因价值的项目。
通过后冻结 GUI 测试对象；测试期间不得悄悄改源码/重启另一构建。

### G18 — Computer Use 双产品验收

依赖可运行冻结批次，不必等所有卡完成才开始已稳定区域。执行 GUI-ACCEPTANCE.md，逐场景记证据。
新缺陷生成 G18-Fxxx 卡；相同根因合并，完成修复后重验原路径及相邻回归。
源码修改与 GUI 操作交替进行，不在一个未知版本上混测。

### G19 — 最终交接与开源门槛

汇总原 #1–11 → 子卡 → 提交/差异 → 自动化 → GUI 证据 → 文档/注释的追踪表。
区分 passed、implemented、blocked、needs-manual-check；未完成的原需求不能改名为后备卡。
附安装包、旧修改、夹带事故、字体许可及公开内容的未决事项；不推送、不发布、不改写历史。
若全部工作阻塞，写明最小恢复动作并结束；有独立任务则继续，不要求维护者夜间答复。
