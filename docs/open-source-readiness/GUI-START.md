# 本轮启动提示词

以下提示词适用于用户选择的执行平台；模型及额度由用户配置，执行会话不自行判断免费时段。
修复后可自动进入 GUI 验收；如果用户安排另一个会话做 GUI，只复制第二段并提供上一会话运行目录。
两个会话不能同时操作同一 checkout 或桌面，交接前须释放锁。

## A. 修复、集成与连续验收

```text
执行本仓库 docs/open-source-readiness/GUI-PLAN.md、GUI-TASKS.md、GUI-ACCEPTANCE.md，通用规则遵循 EXECUTION.md 和当前 AGENTS.md。
这是已确认的完整范围：真人验收 #1–11 全部完成后我才考虑开源。新增功能已获授权，不能套用旧 PLAN 的“不做新产品功能”把它们跳过；分批只是顺序。

你是调度主会话，只负责基线、派发、文件/执行/GUI 锁、账本、证据审阅和交接。具体调查、设计、实现、测试、集成交给子代理，独立验收不能由实现者自证；必须分别安排文档代理和注释代理。模型使用我在平台明确配置的选择，未配置则遵守当前 AGENTS；不自动换昂贵模型。

先读上述文档及原真人验收 issues.md，核对实际 HEAD、工作区和应用版本，从 G00 开始。保留上一轮成果与全部原有修改，不改写历史，不处理未授权的提交夹带处置。只允许精确提交独立验收通过的本轮差异，禁止 git add -u、git add .、git add -A，不推送/发布/部署。

持续按依赖安排任务；一个任务阻塞就落盘证据并转做其他任务，不等我醒来答复。大任务拆子卡，不缩减原需求，不把未完成项改称后备卡。只在所有有价值的范围内任务完成/确实阻塞、我要求停止或工具无法继续时收尾。

冻结可运行批次后，按 GUI-ACCEPTANCE.md 派独立 computer-use 代理实际操作 ReelTerminal 和剪映。GUI 路径不能以 MCP 写状态或源码推演冒充；Agent 路径单独验证。一个桌面只有一个操作者，修复与 GUI 测试交替冻结进行。

收到任务立即开始，不看订阅时段，不自动等到凌晨，不设按时钟收尾。按 EXECUTION.md 在仓库外落盘精确任务卡、状态、证据、运行版本和交接；压缩上下文后从账本恢复。工具中断如实报告，不承诺后台还在运行。

最终交付 #1–11 到实际差异与 GUI 证据的追踪表、文档/注释结论、失败及未测清单、原改动隔离情况、下一恢复入口。没有证据的功能不能判为通过。
```

## B. 独立 GUI 对比会话

```text
在本仓库按 docs/open-source-readiness/GUI-ACCEPTANCE.md 执行独立 GUI 验收，同时读 GUI-PLAN.md、GUI-TASKS.md、EXECUTION.md 及上一个执行会话的 HANDOFF/PROGRESS。
先核对上一个会话已释放仓库和 GUI 锁；未释放不能并行抢占。记录实际应用构建及工作区指纹，不能只相信交接中的 HEAD。

你负责调度独立 computer-use 操作者，在 ReelTerminal 与剪映中使用专用测试项目完成 U01–U18，并按功能 inventory 扩展覆盖。用真实鼠标键盘完成 GUI 操作，导出实际成品；源码、MCP、媒体分析只能用于各自标明的辅助/Agent 验证，不能替代 GUI 行为。

保护用户现有项目和素材；先调用 live capabilities_get 确定新媒体 job 位置。不要购买、登录新账号、上传私有媒体或安装服务解除阻塞。剪映某功能受会员/登录限制时记录并继续其他场景，不影响 ReelTerminal 独立验收。

发现缺陷给出最小复现和前后证据，建 G18-Fxxx。获源码写锁后可按本轮既定范围调度修复、独立审查及分别的文档/注释同步，再冻结新构建重验；不得边改边测未知版本。

我不需要你管理时间或额度。有可执行任务就继续，局部阻塞转做其他项。达到执行规程停止条件时交接；工具无法控制桌面时如实报告并保留恢复入口，不用推测结果补齐矩阵。
```
