# ReelTerminal 1.4.1

## 视频编辑与素材

- 大视频导入时更早显示素材卡片，缩略图在后台生成。
- 减少导入过程中重复读取大型文件的等待；保存工程后使用受控媒体副本，原文件移走后仍可播放。
- 改进命令行的离线帮助、参数校验及受控素材交付，保留明确的目标和编辑权限边界。

## 审阅工作台

- 补齐审阅工具、模型设置和结果导出的中英文界面；切换语言保留未保存的模型配置、区域标签和人工输入。

- 支持按目标安排人工审阅，查看关联对照、采用明确范围的审阅口径，并按人工决定分类导出原文件。
- 保存结果不确定时保留输入并暂停相关写入。先点击“核对本次决定”：已保存的决定无需重复提交，确认未提交后可明确重试。
- 已经保存的决定不会因为后续刷新失败而被误报为未保存。
- 图片、视频单帧和局部区域可独立审阅；MobileSAM 区域分割在本地 CPU 运行，结果仍需人工检查。

## 下载、升级与限制

- 本次分发目标为 Windows x64 安装包和便携 ZIP。其他平台请以发布页实际资产为准。
- Windows 构建未签名，可能显示发布者或 SmartScreen 提示。请从官方发布页下载并核对 `SHA256SUMS.txt`。
- 升级前请阅读 [Windows 升级与备份指南](WINDOWS-UPGRADE.md)。完整解压 ZIP 后运行 `ReelTerminal.exe`；便携包也可能读取现有数据目录。
- 部分视频处理仍需单独安装 FFmpeg/ffprobe。字幕模型及可选 Python/OpenCV 工具按需配置，见 [外部依赖](EXTERNAL-DEPENDENCIES.md)。
- 模型建议与分割结果均需人工确认；持续的文件占用或权限限制仍可能阻止保存。不要反复提交结果未知的决定。
