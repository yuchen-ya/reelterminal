# ReelTerminal 1.3.6 — 审阅导航与返工闭环

保留任务侧栏、紧凑批次下拉框与分组树布局。此版本为本地 Windows x64 安装包和便携 ZIP，未公开发布。

## 交互调整

- 从集合打开条目时展开完整父链、高亮并滚动定位；允许用户随后手动收起。
- 单项统一提供集合返回入口与上一项/下一项，移除图片工作区重复的集合切换。
- 文本单项只显示当前文档；隐藏批量选择和重复裁决按钮。集合保留选择与预览状态，选中项裁决统一放在底栏，整组操作继续明确标注范围。
- 聚合文本卡片复用现有开源 Markdown 渲染器显示紧凑摘要。
- 待审空心圆、保留对勾、返工和丢弃可见状态；新内容使用独立蓝点。
- 返工先输入说明；Enter 确认，Shift+Enter 换行，Esc 取消且不写入。自动推进只跳到范围内尚待审的条目。
- 本组/本批待审清零时显示完成反馈，本批提供发布入口及下一待审批次入口。
- 集合方向键只移动卡片焦点，Enter 打开；正文上下键保留滚动，J/K 或按钮切换条目。
- 零任务提供新建按钮；空任务提供复制接入说明，Agent 权限单独显式切换。
- 粘贴导入默认填入批次名，缺少必要输入时显示原因；文件选择支持拖入。
- 处理记录默认填入最新步骤对比，点击步骤即切换对比。交接界面使用用户可读统计和记录编号，不展示内部 UUID、幂等键及校验术语。

## 已完成的内存专项修复

合入另一审查会话经用户授权修复的两处问题：视频对比使用已有媒体句柄 hook 释放资源；详情缓存随修订、批次、分页和筛选失效，并阻止旧请求回填。同范围下钻/返回仍可复用详情。

## 验证

- Web 相关 9 文件 / 34 项测试通过，覆盖新增导航行为及内存回归。
- GUI 手册 18 项测试通过；Web 与 Desktop 类型检查、桌面生产构建通过。
- 隔离桌面验收：review-interaction、review-collection、review-branches、review-task-menu、review-batch-updates。
- 新流程验收覆盖父链定位、方向键、单项与多选范围、取消返工、带原因返工、自动推进、批次完成、发布、默认前后对比及粘贴导入。
- 使用隔离配置和合成数据，不操作用户真实任务。原生文件拖动的 Explorer 实际接收不在本轮人工验收范围。
- 保留原有构建体积提示、既有 Hook lint 警告以及 jsdom 不支持 video.pause 的测试环境提示；不将它们描述为本轮新增问题或已修复内容。
