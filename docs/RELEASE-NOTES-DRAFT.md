## 主要更新

### 审阅工作台

- 将素材组织为任务、批次和分组；父节点支持画板或分类目录，侧栏提供任务管理、批次切换和内容树。Agent 新内容有未查看提示，查看状态与审阅决定分开。
- 图片、文本、视频等内容可在集合和单项之间导航。支持选中项、本组待审项等明确范围的批量保留、丢弃、返工与恢复；返工填写说明，完成当前范围后提供反馈和后续入口。
- 文本支持 Markdown 阅读、编辑和预览；处理记录支持版本对比。视频可使用明确指定的基准及时间映射对比，无映射时独立查看。
- 独立审阅可导出当前保存版本、原件、采用版本或完整节点包，并可准备文件或文件夹拖出。节点包缺少文件时不能视为完整备份。
- Agent 在同一任务内分组提交新内容或条目版本，保留历史和反馈。新建任务分支已停用；已有分支历史仍可比较和采用，不会自动合并。升级后应重新复制接入说明。

### 项目与素材

- 将本地项目快照保存为模板，并据此创建独立项目，保留原工程和编辑历史。模板不是包含所有源媒体的便携备份，引用的媒体和字体仍须可用。
- 素材面板提供外部资源原站入口；新增经审查的导出副本清理和产物归属管理。
- 新增独立的静态网站演示，复用编辑器并在浏览器本地保存演示项目；不提供真实桌面导出或 Agent 连接。

### 稳定性与体验

- 改进视频解码与帧资源处理、音频环境探测及原生渲染进程超时处理。
- 加强桌面导出参数校验和目标文件保护，保留暂时无法访问的最近项目记录，修正标题栏拖动区域。
- 修复审阅视频对比的媒体句柄释放，以及详情缓存失效和过期请求回填问题。

## 使用与升级提示

- 当前本地构建目标为 Windows x64 安装版和便携 ZIP；本次没有新的 macOS/Linux 包。可用的公开下载以实际 [Releases 页面](https://github.com/yuchen-ya/reelterminal/releases)为准。
- 旧版 Windows 用户应先备份并阅读[升级指南](WINDOWS-UPGRADE.md)。部分媒体工具、字幕和音频功能需要单独安装本地依赖，见[外部依赖](EXTERNAL-DEPENDENCIES.md)。
- 3D 检查器属性修改不单独记录撤销步骤；重要阶段可保留存档点。
