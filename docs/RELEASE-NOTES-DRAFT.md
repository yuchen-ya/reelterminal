### 1.4.0 主要变化

- 内置 Agent 工作时间线：按任务目标组织未来待办、当前审阅场景和已访问记录，提供单项、关联对照与低风险组场景；人工决定及其撤销/重做独立保留，Agent 提案不自动变成人工通过。
- 可明确采用全局或局部审阅口径，保留口径、来源和版本；提供批注自动续写与限定范围的语义搜索。云端模型使用用户配置及明确授权范围，普通批注不会自动修改全局标准。
- 审阅真实本地文件夹，刷新来源变化并保留既有历史；可预览人工决定分布，按选定来源、范围和分类导出原文件及清单。一个片段通过不代表整个原文件已通过。
- 图片、真实解码的视频单帧和区域可作为独立审阅单元。MobileSAM 在本地 CPU 执行正/负点与框选修正；明确保存区域后可分别导出 mask 和带透明 alpha 的 cutout PNG，保存区域不自动批准父项或旧区域。

### 当前验证边界与使用条件

- 隔离 Electron 文本整链及真实 MobileSAM 媒体流程已有开发构建通过记录，包含可见候选色罩、真实解码帧、区域独立人工决定和 PNG 导出。它们不代替最终 1.4.0 包的回归。
- 真实 LLM 的四案例、九单元以及续写/搜索应用链已有有限结果，累计十次请求后停止。仍保留多余追问、建议错引等语义措辞缺口；续写包裹引号和重复前缀修复已用那次真实响应逐字离线 GUI 回放确认，未新增第十一次请求。这不等于总体准确率或所有模型路径质量通过。
- MobileSAM 模型、CPU worker、原生推理运行时与许可证由发行配置打入包内，无需生产 Python，也不会启动时自动下载模型。已有少量自然图与官方转换 parity 证据只证明限定执行与转换一致性；细毛、透明边缘、孔洞及复杂遮挡可能需要人工处理，不承诺通用抠图质量或视频自动传播。
- 图像/视频解码与派生工具仍依赖单独安装的 FFmpeg/ffprobe：使用 PATH，或按既有合同配置 `REELTERMINAL_FFMPEG_PATH` / `REELTERMINAL_FFPROBE_PATH`。本轮不捆绑没有对应源码材料的 GPL FFmpeg 二进制，不将应用描述为零外部依赖。
- 源码构建包含实际 dirty/untracked 改动；最终记录源码 HEAD、dirty 身份和实际构建时间，不以元数据升级冒充重新构建。包版本、签名、SHA-256、模型/worker/PNG 的隔离 packaged 验证均须以新输出目录的实际结果为准。
- 当前未测试新安装向导，也未替用户验证 Explorer/微信是否实际接收到原生拖出文件；这些与应用内“准备导出成功”分别记录。旧版升级仍请先备份并阅读[升级指南](WINDOWS-UPGRADE.md)。

## 主要更新

### 审阅工作台

- 将素材组织为任务、批次和分组；父节点支持画板或分类目录，侧栏提供任务管理、批次切换和内容树。Agent 新内容有未查看提示，查看状态与审阅决定分开。
- 图片、文本、视频等内容可在集合和单项之间导航。支持选中项、本组待审项等明确范围的批量保留、丢弃、返工与恢复；返工填写说明，完成当前范围后提供反馈和后续入口。
- 文本支持 Markdown 阅读、编辑和预览；处理记录支持版本对比。视频可使用明确指定的基准及时间映射对比，无映射时独立查看。
- 独立审阅可导出当前保存版本、原件、采用版本或完整节点包，并可准备文件或文件夹拖出。节点包缺少文件时不能视为完整备份。
- Agent 在同一任务内分组提交新内容或条目版本，保留历史和反馈。新建任务分支已停用；已有分支历史仍可比较和采用，不会自动合并。升级后应重新复制接入说明。

### 项目与素材

- 将本地项目快照保存为模板，并据此创建独立项目，保留原工程和编辑历史。模板不是包含所有源媒体的便携备份，引用的媒体和字体仍须可用。
- 素材面板提供外部资源原站入口；新增经审查的导出副本清理和产物归属管理。
- 新增独立的静态网站演示，复用编辑器并在浏览器本地保存演示项目；不提供真实桌面导出或 Agent 连接。

### 稳定性与体验

- 改进视频解码与帧资源处理、音频环境探测及原生渲染进程超时处理。
- 加强桌面导出参数校验和目标文件保护，保留暂时无法访问的最近项目记录，修正标题栏拖动区域。
- 修复审阅视频对比的媒体句柄释放，以及详情缓存失效和过期请求回填问题。

## 使用与升级提示

- 当前本地构建目标为 Windows x64 安装版和便携 ZIP；本次没有新的 macOS/Linux 包。可用的公开下载以实际 [Releases 页面](https://github.com/yuchen-ya/reelterminal/releases)为准。
- 旧版 Windows 用户应先备份并阅读[升级指南](WINDOWS-UPGRADE.md)。部分媒体工具、字幕和音频功能需要单独安装本地依赖，见[外部依赖](EXTERNAL-DEPENDENCIES.md)。
- 3D 检查器属性修改不单独记录撤销步骤；重要阶段可保留存档点。
