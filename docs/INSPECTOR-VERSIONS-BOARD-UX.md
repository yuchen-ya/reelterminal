# 检查器承载存档与看板

状态：2026-10-09 当前实施方案，交付提交2b77ef8（包含1026293）。按需检查器、紧凑树与历史复制主要流程已独立实测；具体范围和未验证边界见 archive/NODE-UX-RECHECK-2026-10-09.md。已移除被替代的三页签旧方案。

## 最新修订：按需检查器、紧凑谱系与预览复制

### 检查器没有常驻导航

删除始终可见的“属性 / 存档 / 看板”页签及其占位。默认检查器仅显示选中片段属性；无选择时使用原空态。底部“● 存档”和“看板”为仅有的两个入口，不增加行高。

- 点击“存档”才在检查器内容区打开存档树；点击“看板”才打开看板。界面导览专门介绍“存档”入口和阶段性存档，并说明普通保存不创建存档点。沿用检查器标题，只在被打开的内容顶部提供简短标题和一个关闭按钮，关闭后回到当前选择的属性或空态，不保留导航空行。
- 点击时间线/画布对象恢复其属性；看板定位和 Agent 后台选择不抢走面板。预览中选中片段也可检查其属性，但内容编辑控件只读，选择与复制可用。
- 切回存档/看板入口保留同项目的选中项、滚动和未提交看板文本；跨项目不能串目标。切换存档结束旧节点的重命名，不将旧名字带给新目标。
- 打开存档树只定位当前基点，不自动展开一大块重复详情。单击具体节点才显示该节点详情；双击或明确预览动作进入预览。全局预览横幅保留，与检查器当前显示什么无关。

### 树像紧凑的提交图，但用存档语言

参考用户提供的彩色纵向提交图：左侧连续细线与小圆点，右侧紧凑名称行；分叉以清楚的弯折线接回真实父节点，不做大卡片列表。

- 默认每个节点一行，行高约28–32px；名称单行省略，次级短日期在宽度足够时靠右显示，完整名称/日期/摘要用现有统一深色提示或选中详情查看。窄栏隐藏次级日期，不把每行撑成两行。
- 图形使用约6–8px节点、1–1.5px线条和固定图道间距。颜色使用稳定克制的小色板：每个存档点保持稳定色，分支连接线有连续可辨的色彩；未选中变暗但仍看清连线，不褪成几乎不可见的灰。
- 当前基点略亮且有细环，选中行只有轻微底色，去掉整行亮绿色边框；预览用细虚线环/简短标记，与实际当前分开。试剪可保留小菱形，不加大尺寸。
- 单击后的详情只有一份，在树下方紧凑展示摘要、完整时间及必要操作，名称不重复堆叠多层。没有选择时不占详情区域；创建存档点保留为顶部小按钮。
- 行 hover 只做颜色/底色过渡，不膨胀、发光或移动布局；键盘焦点仍清楚。树可以滚动，后台新增节点不抢选中或滚动。首版不新增自动合并或装饰性假连线。

### 预览可复制，粘贴到当前编辑

用户所说“迁移到当前节点”在产品中称为“复制到当前编辑”：存档点本身不可变。复用现有片段剪贴板与粘贴事务，不能把只读预览实现成不可选择、不可复制。

1. 预览中可以选中一个或多个视频、音频、图片、文字片段，Ctrl+C或右键“复制”读取所选内容；允许复制，禁止剪切、删除、拖动和修改历史内容。文本输入框中的Ctrl+C仍复制选中文字，不劫持为片段复制。
2. 按通常习惯，复制后点“返回当前编辑”，在当前时间线设置播放头并Ctrl+V；剪贴板不能因为退出预览而被清空。粘贴使用现有轨道与时间偏移规则，保留多选相对时间、层级、源区间、速度、音量、文字样式及已支持的效果/关键帧/关联关系。
3. 额外提供预览片段右键“复制到当前编辑”，一步复制、返回实际编辑并在该编辑原播放头处粘贴，选中新片段；不自动播放、不采用整个存档、不创建新存档。菜单旁或统一提示解释“放到当前编辑的播放头处”，避免隐藏插入位置。
4. 粘贴新建片段ID并重映射内部关联，引用原确定的素材版本，不能按同名素材或已替换后的mediaId误取内容。复用现有可跨预览生命周期持有的序列化剪贴板数据；保留必要素材/字体依赖，缺失时给出明确说明，不部分粘贴后再失败。
5. 复制不改项目revision、历史或存档；粘贴为目标实际工作区的一次可撤销原子操作，校验目标最新状态。快捷“复制到当前编辑”显式固定该预览关联的项目/工作区，不因GUI切换或Agent更新写到其他项目；冲突保持剪贴板并说明重试，不能静默覆盖。
6. 默认路径为同项目跨存档迁移。已有跨项目粘贴若支持则维持契约并验证依赖；本任务不因此新增跨项目素材管理系统。无可复制选择时菜单禁用，不弹多余提示。

### 本次新增独立验收

- 默认与片段属性模式无三页签、无空占位；只有点击底部入口才打开树/看板，关闭或直接选择片段后恢复正常检查器。
- 真实有分叉的树在窄检查器可读，行高紧凑、日期不挤名称、颜色身份稳定；当前/选择/预览明确，未选中连线仍可辨，右键菜单和所有浮层统一桌面主题。
- 预览中混合多选复制→返回→不同播放头粘贴，验证内容/相对时间/层级/效果与媒体版本，并一次撤销/重做；源存档和源工作区不变化。
- 一步“复制到当前编辑”得到与标准复制粘贴相同结果，落点明确，不全量采用或产生存档；未修改轨道内容不受影响。
- 重复粘贴不复用clipId；试剪预览与普通存档均可复制；文字输入复制、不选择片段、缺失依赖、Agent并发更新及项目切换时均不串目标、不部分写入。
- 帮助中英、导览、项目文档和Agent指引同步删除常驻页签说法，说明预览只读但可复制；API名称不为用户文案变化而改名。原独立报告R03/R05/R06/R07及相关回归仍需通过。

## 保留的基础约定

- Ctrl+S与自动保存只保存当前编辑；创建存档点才记录阶段，内容相同不重复创建。关闭先保存当前编辑，再按每次询问/自动创建/直接关闭偏好处理存档；取消不修改偏好，等待不能自动同意。
- 预览只读但可选择、复制；明确“从这个存档继续编辑”才切换实际内容，之前编辑受保护，可从“找回之前的编辑”恢复，历史后续存档保留。
- 存档引用确定素材版本，不复制整份视频；替换创建新版本，重新链接仅修复同内容位置。回收存档不等于删除素材，清理必须验证所有节点、草稿、任务引用。
- 小时间线视口保留固定工具栏与标尺，轨道头/片段区同步纵向滚动，可达首尾；横向滚动条停留在视口底部。轨道数增加不能撑高整个编辑区，原缩放、播放和拖动行为继续可用。
- 悬停使用现有桌面提示；portal继承同一主题。颜色/底色渐变不放大节点、不改变行高、不闪烁，键盘焦点可辨，尊重减少动态效果设置。
- 用户文案统一“当前编辑 / 创建存档点 / 预览存档 / 返回当前编辑 / 从这个存档继续编辑 / 找回之前的编辑”。英文对应 Current edits / Create save point / Preview save point。内部node/workspace/revision协议保持不变。
- 不做自动合并，不承诺Git级性能；完整描述快照与共享素材为首版实现。大型项目、复杂效果及特殊并发的结论必须来自实际证据。

本方案不替代独立验收报告；未验证项不能因开发者测试通过而升级为用户验收通过。
