# ReelTerminal 1.3.4

日期：2026-10-27（Asia/Shanghai）。Windows x64 本地构建。

- 左侧审阅任务卡片支持右键菜单，展开与收起侧栏均可使用。
- 菜单提供重命名、置顶/取消置顶、归档/取消归档、移到回收站。
- 回收站任务提供还原及永久删除；“永久清空节点”改名为“永久删除任务”，沿用引用检查和确认弹窗。
- 所有操作绑定右键点中的任务；无需先切换当前任务，删除其他任务不会清空当前选择。

验证：侧栏组件测试、18 项 GUI 手册测试、TypeScript 和桌面完整构建通过；开发构建与打包 EXE 的隔离 Electron 回归均覆盖右键非当前任务、移到回收站、确认永久删除及保留其他任务。

包位于 `apps/desktop/release/windows-1.3.4/`。未安装、未公开发布；不修改正在运行的用户任务数据。
