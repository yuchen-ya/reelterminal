## 为什么做审阅工作台

生成的素材往往需要经过多轮**筛选、比较与修补**：

* **多模态批次杂乱**：一次抽卡或脚本跑批可能同时产出几十张候选图、分镜序列、Markdown 语料、清洗表格、视频片段甚至 3D GLB 模型，直接在文件夹或聊天窗口里比对极易迷失版本。
* **局部瑕疵只需定点修补**：单张图片局部崩坏或视频某几帧穿帮时，往往只需要圈注问题、涂抹修补或准确抽出单帧修复，而不必整批重跑。
* **自由画板整理素材**：将参考图、文档和视频排布在同一画布，截取局部内容、保存文件，或导出单项快照继续审阅。

## 工作区与标签

真实任务文件夹与自由画板共用可排序标签栏。打开已有文件夹，或用“新建任务”在当前数据目录创建任务文件夹；关闭标签不删除文件，最近任务可再次打开。目录重命名、移动与复制作用于真实文件，请先确认目标。

## 审阅任务

- **文件管理与审阅分开**：文件目录用于查看、组织、移动和复制素材。从文件夹进入任务工作台后，才按任务目标逐项审阅；复制文件不代表批准内容。
- **人工决定**：查看文字、图片、视频帧或局部区域，记录保留、不采用、返工与批注。决定和草稿保存在任务文件夹的 .reelterminal 中；不采用不删除原件。
- **目标与口径**：设置任务目标，查看来源关联和当前分析。模型建议不替代人工判断；采用或停用局部口径需要明确操作。
- **可选内置模型**：配置自己的模型端点和密钥，并明确授权任务/来源后才发送文本。未授权时仍可完整手动审阅；密钥不提供给外部 Agent。图片区域分割使用随包 MobileSAM 在本地 CPU 运行。
- **保存恢复**：结果不确定时保留输入并暂停相关写入。先核对本次决定，已提交的不重放，确认未提交后可显式重试。持续占用或权限错误会明确报错。
- **结果交付**：先预览范围，再导出明确选择且人工批准的文本、局部结果或原文件。原文件包含多个单元时，预览会披露混合判定，不能把一条保留误当作整份原件全部通过。

本版不迁移旧批次任务，也不恢复旧批次标签。保留旧数据与备份；不要把旧协议的批次、版本包和返工命令当作当前文件夹审阅入口。与视频工程的联动仍有限，审阅不自动编排时间线。

## 自由画板

自由画板用于混合媒介排布、局部修补和截图输出，画布背景为白色：

- **7 类混合媒介同板排布**：
  - 直接拖入或粘贴**图片、文本（`.txt`/`.log`）、视频、3D GLB、Markdown（`.md`）、本地 HTML（`.html`/`.htm`）**，或粘贴单独的 **HTTP/S 链接**生成网页容器。
  - 视频容器支持播放定位与「截取当前帧」入板；GLB 容器支持旋转缩放与「截取当前视角」入板；图片支持裁剪、90° 旋转、翻转与源像素修补（画笔/橡皮/仿制图章/外部贴片）。
- **受管文档与隔离原生浏览**：
  - Markdown 导入仅保留文档目录内实际引用的受管本地资源，支持源码编辑与相对链接打开新容器。
  - 本地 HTML 自动通过隔离 Chromium 视图生成首屏快照（仅加载本地受管资产，不访问外网）；网页容器默认仅展示 URL，点击「进入浏览」才在固定区域启动无 Node/preload 权限的原生 Chromium 视图，随时可「截图当前视口并返回画板」。
- **区域冻结 PNG 与单文件输出**：
  - 「区域截图」支持矩形、多边形或自由选区，可调整多边形顶点并选择透明背景；输出 PNG 可**拖出文件、复制到剪贴板、保存到本地或作为新图加入画板**。
- **文件输出与审阅快照**：
  - 画布内拖动内容用于调整布局。要拖出系统文件，选中内容后点击「单个文件：拖出 / 保存」，再拖动输出面板的「拖出文件」按钮。
  - 选中单个容器，点击「导出此内容为审阅节点」可创建独立快照；后续画板编辑不会同步修改已导出的节点。

详细操作请参阅 📖 **[自由画板使用说明 (docs/HUMAN-BOARDS.zh-CN.md)](docs/HUMAN-BOARDS.zh-CN.md)**。

## 面向 AI Agent 的审阅与修补 CLI

外部 Agent 的视频编辑命令通过应用复制的启动命令连接，再用 tools / describe 查询当前契约，显式绑定目标和版本；切换标签不授予其他内容的读取权限。

当前真实文件夹任务的人工决定、草稿和模型密钥通过桌面内部接口管理，尚未向外部 Agent 提供同等命令入口。旧 review.* 协议仍有兼容代码，但不能据此推断它可操控当前任务。私人自由画板保持独立；只有用户明确导出的快照才成为可交付内容。连接说明见 [外部 Agent 指南](docs/AGENT-GUIDE.md)。
